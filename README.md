# The Social Collapse

A satirical strategy game by **Axiom Games**. You play a made-up government trying to sell five terrible policies to America using paid news, fake crowds, bots, and an online critics phone, without getting exposed or going bankrupt.

Play it: https://the-social-collapse.pages.dev

## Folders
- `public/` - the live website (this is what Cloudflare Pages serves)
- `src/` - source pieces used to build `public/index.html` (game template, US map shapes, Axiom intro)
